On Gruvbox & Cozy Reading

created 2026-06-02 status evergreen #theme #aesthetic

Gruvbox is a retro groove color scheme built around warm, low-saturation tones that stay easy on the eyes through long writing sessions. This note is a living preview — every element below is styled exactly as the [[Gruvbox Cozy]] theme renders it in Obsidian.

Note

The palette never uses pure black or white. Backgrounds sit on warm browns; text rests on soft cream — that's the whole secret to the cozy feel.

Why it feels warm

Every neutral leans slightly toward brown and amber instead of cold gray. Pair that with muted accent colors and you get contrast that's readable without ever being harsh.

"Keep colors easily distinguishable, contrast enough, and still pleasant for the eyes."

The reading checklist

  • Warm background, never pure black
  • Cream foreground for body text
  • Headings tinted by level
  • One confident accent for links & cursor

Task states

Beyond done/undone, the theme colors each checkbox state (works with the Tasks plugin):

  • To do
  • Done
  • /In progress
  • !Important
  • ?Question
  • >Forwarded
  • ×Cancelled

Syntax highlighting

Code uses the full palette — set inline like --background-primary, or in fenced blocks:

theme.csscss
/* map gruvbox → obsidian */
.theme-dark {
  --background-primary: #282828;
  --text-normal:        #ebdbb2;
  --interactive-accent: #fe8019;
}

function cozy(mode) {
  return mode === "dark"
    ? "retro groove"
    : "cream";
}
