# Gruvbox Cozy Soft

A warm, retro-groove theme for [Obsidian](https://obsidian.md), built on the
[Gruvbox](https://github.com/morhetz/gruvbox) palette by Pavel Pertsev.

This is the **soft** contrast edition — the warmest, coziest background (#32302f).
It works without any plugin. Looking for the other depths? Try **Gruvbox Cozy Soft**,
**Gruvbox Cozy Medium**, and **Gruvbox Cozy Hard**.

Tested against Obsidian **1.13.x** (June 2026).

## Install

1. Open your vault's `.obsidian/themes/` folder.
2. Create a folder named `Gruvbox Cozy Soft` and copy `theme.css`, `manifest.json` and `versions.json` into it.
3. In Obsidian: **Settings → Appearance → Themes** and select **Gruvbox Cozy Soft**.

## Customize (optional)

Install the **Style Settings** plugin to switch accent color (7 options), reading font
(sans / serif / mono), colored headings, italic emphasis, the pixel-art maple-leaf
watermark (+ opacity), the dot-grid note background (+ strength), and colored task states.
Or override any `--gb-*` variable in a CSS snippet.

> 🍁 Bonus: the sidebar maple leaf also ships as ASCII art in the repo's `art/maple-leaf.txt`.
